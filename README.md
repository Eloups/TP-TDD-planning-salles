# TP1 Test Driven Development
## Dépendances

Ce projet nécessite le langage Rust.\
Vous pouvez installer le langage en suivant ce lien : https://rust-lang.org/tools/install/

## Installation et lancement du projet

Vous pouvez lancer un build via la commande suivante (optionnel) :
```bash
cargo build
```

Vous pouvez lancer le projet via la commande suivante :
```bash
cargo run
```

## Tests automatisés

Vous pouvez lancer les tests du projet via la commande suivante :
```bash
cargo test
```

## Documentation

Vous pouvez générer et ouvrir la documentation du projet via la commande suivante :
```bash
cargo doc --open
```
